SPACE TECHNOLOGIES WEBSITE

index.html    the whole website (open it in a browser, or upload to GitHub)
favicon.svg   browser tab icon
logo-3d.svg   3D logo with name

To receive enquiries: open index.html in a text editor, find CONFIG near the top of the script,
and fill EMAIL (or FORM_ACTION). Save and upload again.

GitHub upload: Add file > Upload files > drag index.html and favicon.svg > Commit changes.
GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
